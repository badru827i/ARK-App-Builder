# ARK App Builder

**Visual no-code / low-code Android app builder by ARK TEKNOLOGY.**

## Vision

Build Android apps by dragging components onto a canvas and connecting functional nodes — without manually writing Java/Kotlin for normal app features.

## Planned capabilities

- Visual drag-and-drop UI builder
- Node-based logic and event connections
- Buttons, ImageButtons, text, forms, sliders and switches
- Camera, microphone, audio, video and file nodes
- USB / storage / Bluetooth / GPS / sensors
- Web/API and network nodes
- AI nodes for vision, text and automation
- Login and local database nodes
- Variables, conditions, loops, timers and events
- Live project JSON format
- Android Java/Kotlin project generator
- GitHub Actions APK build pipeline
- APK/AAB release builds
- Custom Code Node for advanced functions
- AI-assisted app generation
- Phone-friendly builder UI

## Architecture

`UI Editor -> Node Graph -> Project Model -> Code Generator -> Android Project -> GitHub Actions -> APK/AAB`

## Development strategy

The builder is developed in buildable stages. The first foundation focuses on the visual editor, reusable node definitions, project serialization and a clean architecture that can later generate complete Android projects.
